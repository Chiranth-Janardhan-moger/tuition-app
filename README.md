# 🎒 Tuition Management System - Release Portal

Backend assets, version logs, and release APK distributions for the tuition mobile application.

## 📱 Features
- **Real-Time Attendance**: Visual tracker for student check-ins.
- **Database Query Optimizations**: Optimized queries for fast rendering.
- **Autoupdate Handler**: Serves `version.json` containing the latest release notes and APK download links.
